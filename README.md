## Running the Projects

Each project is independent. See its own README for setup and run instructions. General prerequisites across the repo:

- Python 3.8+
- Project-specific dependencies listed in each subfolder's `requirements.txt` (where applicable)

```bash
cd project-a
pip install -r requirements.txt   # if present
python main.py
```
